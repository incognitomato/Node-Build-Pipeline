# Node-Build-Pipeline

A **zero-dependency Node.js static site generator** built to compile the <a href="https://retro.tomverse.de" target="_blank" rel="noopener">[CRT & CATS]</a> blog experiment. The pipeline uses a custom `build.js` engine to parse templates, inject production JSON-LD schema layouts, and update the global sitemap. It isolates draft code paths safely until components are ready for indexing.

This is a simplified, fully working architectural example.

---

## 📂 Project Structure

All assets of the page are located inside the `source/assets` folder. This folder serves as the root workspace of the web application.

```text
.
├── source/
│   └── assets/
│       ├── css/          # Stylesheets
│       ├── images/       # Web-optimized assets (.webp files generated by optimize.js)
│       ├── sections/     # HTML layout templates (header, menu, etc.)
│       ├── 404.html      # Error fallback page
│       ├── favicon.ico   # Site icon
│       └── index.html    # Base website entry template
├── build.js              # The main pipeline compiler engine
├── optimize.js           # Graphic helper utility for asset compression
└── README.md             # Project documentation
```

---

## 🚀 Running the Build

### 🖼️ Step 1: Optimize Graphical Assets (Optional)
Before generating pages, you can run the image processing helper. It automatically converts high-resolution source graphics into modern, lightweight `.webp` formats and places them directly into the deployment assets directory:

```bash
node optimize
```

### ⚡ Step 2: Compile the Static Website
To start the core build process, open your node console (e.g., the integrated terminal in VS Code) and execute the pipeline engine:

```bash
node build
```

A successful compilation loop will output the following message logs directly into your console:

